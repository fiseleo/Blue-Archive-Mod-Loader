### 🚀 快速开始

```bash
# 1. 编译
cd "Blue Archive Mod Manager-C#"
dotnet build

# 2. 运行
dotnet run

# 或直接运行可执行文件
.\bin\Debug\net10.0-windows\"Blue Archive Mod Manager-C#.exe"
```

### 📋 实现详情

#### GamePathManager
- Steam 注册表查询
- 自动游戏检测
- 驱动器递归扫描
- 游戏路径保存

#### ModManager
- MOD 文件导入
- 数据持久化 (JSON)
- MOD 启用/禁用
- 删除功能
- 应用/卸载框架

#### StudentIndexManager
- 角色信息识别
- 多语言支持
- 索引数据管理

#### WebViewBridge
- C#-JavaScript IPC
- 异步通信
- 事件通知

#### SettingsManager
- JSON 配置管理
- 类型安全访问
- AppData 管理

### 🔄 IPC 通信流程

```
前端 (JavaScript)
    ↓
window.chrome.webview.postMessage()
    ↓
WebViewBridge → C# 处理器
    ↓
业务逻辑执行
    ↓
返回结果到前端
    ↓
UI 更新
```
